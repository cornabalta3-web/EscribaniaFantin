# Prototipo

Un solo archivo, `index.html`. **Se abre con doble clic**, no hay que instalar nada.

## Para qué sirve

Para tener algo concreto que mirar y discutir. Es mucho más fácil decir
"acá falta el estado civil" mirando una pantalla que imaginándola.

## Qué tiene

- **Expedientes** — listado, búsqueda, filtro por estado, ficha con historial,
  cambio de estado, alta de expediente nuevo.
- **Partes** — padrón de personas físicas y jurídicas, con alta.
- **Vencimientos** — lo que vence primero, arriba.

## Qué NO es

- Los datos quedan guardados **solo en el navegador de esa computadora**. No se
  comparten entre PCs y no hay copia de seguridad.
- No hay usuarios ni contraseñas.
- **No cargar datos reales de clientes.** Es una maqueta.

Cuando estemos de acuerdo en cómo tiene que ser, se reescribe como aplicación
web de verdad, con base de datos y usuarios.

## Cómo lo usamos para decidir

Abrilo, tocá todo, y por cada cosa que falte o sobre abrí un **Issue** en GitHub.
Ese es el material con el que después construimos el sistema real.
