# Sistema de Gestión Notarial

Sistema integral de gestión para escribanía: expedientes, partes, protocolo,
documentos, agenda y vencimientos.

Proyecto en fase de **definición**. Todavía no hay código: primero estamos
escribiendo *qué* tiene que hacer el sistema y *cómo* vamos a trabajar.
